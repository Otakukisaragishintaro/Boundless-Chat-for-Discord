# Boundless Chat for Discord 安装与配置教程

## 1. 安装前准备

- Android 8.0 或更高版本。
- 已取得 Root 权限。
- 已安装支持 LibXposed API 102 的 LSPosed。
- Discord Android Stable 版本为 340.13（versionCode 340013）或 352.17（versionCode 352017）。

本模块通过 Hook Discord 客户端工作。其他 Discord 版本不保证兼容；Discord 更新后，请先确认项目是否发布了对应版本适配。

## 2. 安装模块

1. 安装本项目发布的模块 APK。
2. 打开 LSPosed，找到并启用 **Boundless Chat for Discord**。
3. 在模块作用域中勾选官方 Discord 应用（包名 `com.discord`）。
4. 按 LSPosed 的提示完成所需重启，然后打开模块设置页面。

## 3. 配置翻译服务

- **服务协议**：根据服务商选择 OpenAI Compatible、OpenAI Responses 或 Anthropic Messages。
- **API URL**：填写服务商提供的基础地址，例如 `https://api.openai.com/v1`。模块会自动追加对应协议端点。
- **API 密钥**：填写服务商发放的密钥。不要将密钥提交到公开仓库或截图中。
- **模型**：填写服务商支持的模型名称。
- **目标语言**：接收消息翻译使用的目标语言。
- **流式请求**：按服务端协议能力开启或关闭。

点击“检查设置”验证本地配置，再使用“测试连接”和“测试翻译”验证请求及译文。测试按钮不会向 Discord 聊天发送消息。

## 4. 配置翻译发送按钮

1. 在设置页找到“管理发送按钮”。
2. 点击“添加语言按钮”。
3. 设置按钮显示名称和目标语言。
4. 如有需要，编辑该按钮独立的提示词。提示词支持 `{{target_language}}` 占位符。
5. 完成按钮编辑后，回到主设置页面并保存整个配置。

最多可以设置 8 个发送语言按钮。每个按钮独立保存目标语言和提示词，不会改变接收消息的翻译目标语言。设置页中的“测试发送翻译”只测试翻译结果，不会真的发送 Discord 消息。

在 Discord 聊天输入框中输入内容后，Discord 原生发送控件出现时，模块才显示对应的翻译发送入口。点击后会先翻译当前草稿，再调用 Discord 原生发送动作。输入框为空或原生发送控件不可用时，翻译按钮保持隐藏。

## 5. 保存、同步与生效

1. 点击“保存”。
2. 等待状态显示设置已保存，并确认 LSPosed 同步成功。
3. 完全停止 Discord，再重新打开 Discord。

模块设置保存在本机；如果 LSPosed 尚未连接，可以先保存，待服务连接后同步。若设置同步失败，先处理 LSPosed 连接问题，再重启 Discord。

## 6. 翻译范围

- **默认翻译**：未命中规则的位置默认翻译，可通过规则排除特定位置。
- **默认不翻译**：未命中规则的位置默认不翻译，可通过规则允许特定位置。
- 频道规则优先于服务器规则。
- 删除某条规则后，该位置恢复继承上一级规则或默认策略。

服务器和频道 ID 需要在 Discord 开发者模式中复制后手动输入。规则修改后，先应用到草稿，再保存、同步并重启 Discord。

## 7. 常见问题

**没有出现翻译图标或按钮**
- 确认模块已在 LSPosed 启用，作用域包含 `com.discord`。
- 确认 Discord 版本属于项目支持列表。
- 确认自动翻译开关和 API 配置正确。
- 发送翻译入口只会在 Discord 原生发送控件实际出现后显示。

**设置保存了但 Discord 没有生效**
- 检查 LSPosed 服务是否连接、同步是否成功。
- 强制停止并重新启动 Discord。

**API 测试失败**
- 检查 API URL、密钥、模型、协议、网络和服务商配额。
- 阅读测试结果中的错误类别和 HTTP 状态。
- 非 2xx 上游错误正文可能包含敏感内容，分享日志前请检查。

**更新模块时无法覆盖安装**
- 本项目发行 APK 使用项目自己的签名密钥。只有使用相同发行签名构建的后续版本才能直接覆盖安装；如果签名不同，Android 会拒绝更新。不要在尚未考虑设置数据的情况下贸然卸载旧版本。

## 隐私说明

符合条件的消息文本会发送到你自行配置的翻译服务。API 密钥保存在模块私有设置和本机 LSPosed remote preferences。请自行评估翻译服务商的数据处理政策。项目日志启用时，非 2xx 上游 HTTP 错误正文可能被记录，分享前请检查。
