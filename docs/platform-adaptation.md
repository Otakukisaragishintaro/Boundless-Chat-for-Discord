# 聊天宿主适配层说明

本文用于准备未来接入其他聊天软件的目录边界。当前改动只增加包目录和说明，不搬迁 Java 类、不修改 Hook 注册顺序、不改变配置键或运行时调用路径。

## 当前已建立的目录

```text
io/github/otakukisaragishintaro/boundlesschatdiscord/
├── core/                 # 通用配置、同步、缓存、调度、状态和文本处理
├── translate/            # 通用 API、协议编码/解析、流式请求和测试
├── ui/                   # Android 设置页和通用设置编辑器
├── hooks/                # 当前已验证的 Discord 专属 Hook 实现，暂时保留原位置
└── platform/
    ├── common/           # 未来跨聊天宿主适配契约的预留包
    └── discord/          # Discord 专属适配实现的目标目录
```

Java 包目录由 `package-info.java` 保持可追踪；Git 不保存空目录。以上预留包当前不含运行时适配器，也不参与 Hook 注册。

## 职责边界

### 通用层

- `core/`：配置数据结构、配置同步事务、缓存、翻译范围、任务状态、调度、内容分段、哈希和通用工具。
- `translate/`：供应商协议、API 请求、SSE/JSON 响应解析、译文校验入口和 API 测试。
- `ui/`：不直接 Hook 宿主聊天视图；负责向通用配置模型读写设置。

新增聊天宿主时应直接复用以上能力。不要在 Discord 或其他宿主目录重新创建 API 客户端、缓存数据库、请求队列、配置存储或第二套翻译流程。

### 宿主适配层

未来的 `platform/common/` 只放真正跨宿主稳定的接口与数据模型，例如：

- 宿主消息捕获结果及规范化文本/节点描述。
- 当前消息身份、编辑版本和显示位置的抽象。
- 将翻译结果投影回宿主原生文本结构的接口。
- 输入框状态、发送动作和宿主生命周期的适配契约。

`platform/discord/` 只放 Discord 专属内容，例如：

- Discord 包名、版本识别及对应 Hook profile。
- Discord 混淆类、方法、字段、参数和构造器定位。
- Discord 消息行、正文、Embed、Poll 的绑定与原生节点重建。
- Discord 输入框监听、翻译发送按钮布局、原生发送行为。
- Discord Activity、View 及列表复用的生命周期适配。

其他聊天软件应拥有单独的宿主子包；不得把宿主特定类名、View 结构或发送按钮定位写进 `core/` 或 `translate/`。

## 为什么本轮不直接搬迁现有 Hook 类

当前 `hooks/` 内部并不是一组互不相关的 UI 文件：`HookBridge` 协调身份映射、范围判定、缓存、调度与翻译引擎；消息、Embed、Poll、输入框、图标与原生重建代码之间存在大量包级和跨包引用。只移动目录会同时影响 Java package、import、可见性、测试引用和 Hook 生命周期装配。

因此本轮采取无行为变化的准备方式：

1. 保留现有 `hooks/` 包路径及所有调用关系。
2. 新建 `platform/common/` 与 `platform/discord/` 包目录及中文职责说明。
3. 在 `hooks/package-info.java` 标明其现有实现属于 Discord 宿主层，并指向未来迁移目标。
4. 不新增并行 Hook、不增加兼容分支，也不更换现有业务入口。

这样独立目录已经进入源码树，后续可在单独的迁移变更中逐类迁移并同步更新引用，而不是现在先制造一次大范围包路径改动。

## 未来迁移顺序

1. 先审查现有 Hook 到通用业务层的依赖，明确每个跨层调用的输入/输出。
2. 在 `platform/common/` 抽取最小且真实需要的宿主接口，不提前设计未使用的抽象层。
3. 把 Discord 的 Hook 实现整批迁入 `platform/discord/`，同步 package、import、资源配置和测试引用。
4. 由模块入口按目标包选择唯一宿主适配实现；每个宿主只有一套消息捕获、按钮交互和渲染路径。
5. 通过 GitHub Actions 完成构建、单元测试、APK 资源检查与签名验证；再以实际 Discord 设备验证消息绑定、按钮布局、发送动作、列表复用和生命周期。

在迁移验证完成前，`hooks/` 仍是实际 Discord 代码位置；`platform/discord/` 是明确标注的目标目录，不应误认为已经完成类文件迁移。
