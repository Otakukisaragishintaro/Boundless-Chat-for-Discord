## 1.5.1

### 性能优化
- 减少 Discord 消息渲染路径中的无效诊断开销：日志关闭或一次性日志已记录时，不再构造调用堆栈和诊断文本摘要。
- 为视图与消息登记表增加弱引用反向索引，避免视图注销和关联查找时反复扫描整个登记表。
- 将跨进程诊断日志队列限制为最多 256 条；队列拥挤时优先丢弃普通信息日志，优先保留警告，并在后续日志中报告丢弃数量。
- 复用诊断日志数据库帮助类，并将历史记录清理调整为批量执行，减少频繁数据库初始化和写入开销。

### 行为与兼容性
- 翻译提示词、分段策略、占位符/提及/网址保护、译文完整性校验、翻译调度限制、缓存键及用户可见翻译行为均未改变。
- 项目诊断日志仍默认关闭。
- 增加惰性日志和视图反向索引相关回归测试。
