## 新功能

- 新增长消息分段请求选项，默认关闭。开启后，只有整条消息超过触发字数且包含空行段落边界时，才会按完整段落分组发送翻译请求，再合并成一条译文；不会强行切开单行或单个段落，过短的末尾段落会并入前一组。
- 新增 Discord 内容保护选项，可分别控制用户/身份组提及、@everyone/@here、频道引用/自定义表情及网站链接的保护。默认全部开启；翻译完成后恢复原始内容，减少翻译服务改写 Discord 特殊语法的情况。

## 修复与改进

- 修复部分翻译服务在正文开头为受保护内容时遗漏请求包装起始标签、导致正常译文被防损坏校验误拒绝的问题；仅清理符合受保护标记边界的孤立末尾包装标签，其他包装污染仍会被拒绝。
- 改进实际翻译失败日志，增加失败阶段、错误分类、HTTP 状态及长度受限的请求/译文预览，便于区分网络、响应解析和译文校验问题。

## 注意事项

- 长消息分段请求属于实验性选项，默认关闭。启用后可能增加 API 请求次数和 Token 消耗；仅在空行段落边界处分组，单个超长段落仍作为一次请求发送。
- 内容保护选项默认开启且可分别关闭。若翻译服务不能稳定保留保护标记，相关译文仍会被防损坏校验拒绝，不会自动猜测或修补缺失的原始内容。
- 启用项目日志时，翻译失败诊断预览可能包含部分消息原文或译文；分享日志前请检查并遮盖敏感内容。
